Heart Disease Prediction Using SVM

This Machine Learning application uses Support Vector Machine (SVM) Classification to predict whether a patient is at risk of heart disease based on important medical parameters.

Project Objective

To identify heart disease risk at an early stage using machine learning and healthcare data.

Algorithm Used

Support Vector Machine (SVM) Classification is used to classify patients into disease and non-disease categories.

Input Features

Age, Sex, Blood Pressure, Cholesterol, and Maximum Heart Rate.

Prediction Output

Predicts whether a patient is likely to have heart disease or not.

Dataset Information

Features

5

Target

Heart Disease

Problem Type

Classification

Algorithm

SVM

Medical Parameters

Age

Patient age in years.

Sex

Male (1) or Female (0).

Blood Pressure

Systolic blood pressure measurement.

Cholesterol

Blood cholesterol level.

Maximum Heart Rate

Highest heart rate achieved during activity.
