## 💻 Installation

### Clone Repository

```bash
git clone https://github.com/abhaysingh-coder/Machine-Learning-Projects-Collection.git
```

### Navigate to Repository

```bash
cd Machine-Learning-Projects-Collection
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```
