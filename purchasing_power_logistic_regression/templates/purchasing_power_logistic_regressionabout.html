Purchasing Power Prediction Using Logistic Regression

This Machine Learning application predicts whether a customer is likely to purchase a product based on Age and Estimated Salary using the Logistic Regression Classification Algorithm.

Project Objective

To analyze customer purchasing behavior and predict whether a customer is likely to buy a product.

Algorithm Used

Logistic Regression is used to classify customers into purchasing and non-purchasing categories.

Input Features

Age and Estimated Salary are used as input features for customer purchase prediction.

Prediction Output

Predicts whether a customer will Purchase or Not Purchase.

Dataset Information

Problem Type

Classification

Target

Purchase Status

Algorithm

Logistic Regression

Output

Purchase / No Purchase

Key Evaluation Factors

Age

Customer age and buying behavior patterns.

Estimated Salary

Customer income and purchasing capability.

Market Trends

Consumer purchasing tendencies and preferences.

Customer Profile

Overall purchasing potential evaluation.
