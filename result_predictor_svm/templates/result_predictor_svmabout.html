Result Prediction Using Support Vector Machine

This Machine Learning application predicts whether a student is likely to pass or fail based on learning activities, study habits, assignments, and engagement metrics.

Project Objective

To identify students at risk and predict academic performance using educational activity data.

Algorithm Used

Support Vector Machine (SVM) is used to classify students into Pass and Fail categories.

Input Features

Study Hours, Videos Watched, Assignments Completed, Forum Activity and Days Inactive.

Prediction Output

Predicts whether a student is likely to Pass or Fail.
