Loan Approval Prediction Using Decision Tree

This Machine Learning application predicts whether a loan application will be approved or rejected based on applicant information and financial details using the Decision Tree Classification Algorithm.

Project Objective

To assist financial institutions in evaluating loan applications quickly and accurately using machine learning.

Algorithm Used

Decision Tree Classification is used to determine whether a loan application should be approved or rejected.

Input Features

Applicant income, education, employment status, credit history, loan amount, and other details.

Prediction Output

Predicts whether the loan application is Approved or Rejected.

Dataset Information

Problem Type

Classification

Target

Loan Status

Algorithm

Decision Tree

Output

Approve / Reject

Key Evaluation Factors

Applicant Income

Monthly or annual income of the applicant.

Loan Amount

Total amount requested by the applicant.

Credit History

Past loan repayment behavior and credit score.

Education

Graduate or non-graduate qualification.

Employment Status

Self-employed or salaried professional.

Dependents

Number of family dependents.
