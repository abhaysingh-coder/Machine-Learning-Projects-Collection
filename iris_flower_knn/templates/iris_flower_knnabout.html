Iris Flower Classification Using KNN

This Machine Learning application uses the K-Nearest Neighbors (KNN) algorithm to classify Iris flowers into different species based on flower measurements.

Project Objective

To classify Iris flowers into Setosa, Versicolor, and Virginica using machine learning techniques.

Algorithm Used

K-Nearest Neighbors (KNN) identifies the nearest similar flower samples and predicts the flower species.

Input Features

Sepal Length, Sepal Width, Petal Length, and Petal Width.

Prediction Output

Predicts Iris-setosa, Iris-versicolor, or Iris-virginica.
