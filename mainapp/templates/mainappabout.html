About Project

Machine Learning Models Portfolio

This website is a Django based Machine Learning portfolio that contains multiple prediction and classification models in one place.

Project Purpose

The main purpose of this project is to showcase different Machine Learning models with a clean web interface where users can open and test each model.

Technologies Used

This project is built using Python, Django, HTML, CSS, JavaScript, Scikit-Learn, Pandas, NumPy, and Joblib.

ML Algorithms

It includes models based on Linear Regression, Logistic Regression, Decision Tree, Random Forest, KNN, SVM, and Lasso Regression.
