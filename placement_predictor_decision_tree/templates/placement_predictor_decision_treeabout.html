Placement Prediction Using Decision Tree

This Machine Learning application predicts whether a student is likely to get placed based on academic performance, aptitude skills, and educational achievements.

Project Objective

To help students understand their placement opportunities using Machine Learning and educational data.

Algorithm Used

Decision Tree Classification is used to determine whether a student is likely to be placed or not.

Input Features

Academic marks, aptitude scores, communication skills, and student profile details.

Prediction Output

Predicts whether a student is Placed or Not Placed.
