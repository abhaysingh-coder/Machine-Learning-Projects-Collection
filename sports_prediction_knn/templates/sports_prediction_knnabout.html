Sports Performance Prediction Using KNN

This Machine Learning application predicts sports performance categories using the K-Nearest Neighbors (KNN) algorithm. It helps coaches, analysts and athletes evaluate performance based on training and match statistics.

Project Objective

To predict sports performance and assist athletes in improving their training and competition outcomes.

Algorithm Used

K-Nearest Neighbors (KNN) predicts performance based on similarity with previous sports records.

Input Features

Training hours, fitness score, match statistics, performance metrics and player activity.

Prediction Output

Predicts sports performance category and expected athlete outcome.
