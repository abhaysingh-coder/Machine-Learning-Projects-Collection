Iris Flower Classification Using Decision Tree

This Machine Learning application predicts the species of an Iris flower using flower measurements and the Decision Tree Classification Algorithm.

Project Objective

To classify Iris flowers into Setosa, Versicolor, or Virginica using flower measurement data.

Algorithm Used

Decision Tree Classification is used to learn patterns and classify flower species based on feature values.

Input Features

Sepal Length, Sepal Width, Petal Length, and Petal Width.

Prediction Output

Predicts one of three flower species: Setosa, Versicolor, or Virginica.
